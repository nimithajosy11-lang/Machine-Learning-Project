PROJECT CAPABILITIES

Features of the System

An end-to-end machine learning workflow presented through a simple web interface.

01

Data Analysis

The project dataset can be explored through descriptive statistics, distributions, correlations and outlier analysis.

02

Six ML Models

Linear Regression, Decision Tree Regression, Random Forest Regression, K-Nearest Neighbors (KNN) Regression, AdaBoost Regression and Gradient Boosting Regression are compared.

03

Model Evaluation

MAE, MSE, RMSE and R² are calculated using a held-out test dataset.

04

USD to INR

The predicted revenue is displayed in USD and converted to Indian rupees on the same page.

05

Automatic Model Selection

The application selects the model with the highest test-set R² score.

06

No Pickle Required

Models are trained from the CSV when the application starts. No saved model file is needed.

ABOUT THE PROJECT

Making Business Data Useful

Google Revenue Prediction is a machine learning project that estimates total revenue using business, financial and digital-performance indicators. It demonstrates data preprocessing, exploratory data analysis, regression modelling and evaluation.

A Flask web application allows users to submit inputs and view the model's estimated revenue without running Python commands for each prediction.
