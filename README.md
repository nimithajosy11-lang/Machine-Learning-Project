# 📊 Google Revenue Prediction Using Machine Learning

## 📌 Project Overview
Google Revenue Prediction is a machine learning project that predicts Google's total revenue based on 11 input features. The project implements six regression algorithms, compares their performance, and uses the best-performing model to generate revenue predictions.

The predicted revenue is displayed in **US Dollars (USD)** and converted into **Indian Rupees (INR)**.

## 🎯 Objectives
- Predict total revenue using machine learning.
- Train and evaluate six regression models.
- Identify the best-performing model.
- Display predicted revenue in USD and INR.
- Provide a simple, user-friendly web interface.

## 📂 Dataset Details
- **Total Records:** 8,000
- **Input Features:** 11
- **Target Variable:** `Total_Revenue_Million_USD`
- **Train-Test Split:** 70:30

The input features include search queries, YouTube users, Google Cloud revenue, advertising revenue, employee strength, R&D expenditure, AI investment, operating expenses, market share, economic growth, and digital engagement.

## 🤖 Machine Learning Algorithms
The project uses the following six regression algorithms:

1. Linear Regression
2. Decision Tree Regression
3. Random Forest Regression
4. K-Nearest Neighbors (KNN) Regression
5. AdaBoost Regression
6. Gradient Boosting Regression

**Best Model:** Gradient Boosting Regression
